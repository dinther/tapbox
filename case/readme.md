The case was created with OpenSCAD. This is a parameteric script driven open source cad program which is perfect for the creation of 3D printable parts. You can find OpenSCAD here: https://openscad.org/

You can also just use the STL files included in this folder. These are optimized for the parts I have on hand but they may suit you too.

I textured part of the case in order to hide layer lines that are otherwise unavoidable with FDM printing. For this I used https://bumpmesh.com an excellent browser based editor. I used texture.png in this program.
