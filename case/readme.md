## CAD Files
The case was created with OpenSCAD. This is the included tapbox_case.scad file. This is a open source parametric script driven cad program which is perfect for the creation of 3D printable parts. You can find OpenSCAD here: https://openscad.org/

The bottom three lines of the source can be uncommented for the part you want to generate.

## STL Files
You can also just use the STL files included in this folder. These are optimized for the specific parts I have on hand but they may suit you too.

## Texturizing
I textured part of the case in order to hide layer lines that are otherwise unavoidable with FDM printing. For this I used https://bumpmesh.com an excellent browser based stl texturizer. I uploaded texture.png for the texture in this program.
